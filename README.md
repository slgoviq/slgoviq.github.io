**SLGovIQ** is a fast, ultra-minimalist, client-side exam practice platform tailored specifically for Sri Lankan public sector competitive examination candidates. It offers realistic exam hall simulations, strict countdown timers, and step-by-step **Short Methods (කෙටි ක්‍රම / குறுக்கு வழிகள்)** in **Sinhala (සිංහල)**, **English**, and **Tamil (தமிழ்)**.

---

## 🌟 Key Features

- ⏱️ **Real-Time Exam Engine Island:** Strict countdown timer (auto-submits when time expires). Progress is gracefully preserved in `sessionStorage` against accidental page reloads.
- ⚡ **Speed Solutions & Short Methods:** Every question provides an instant, tested shortcut or mental arithmetic rule to help candidates solve questions in under 45 seconds.
- 🌐 **100% Trilingual UI & Paper Collections:** Instant one-click language switching across the entire platform (Sinhala, English, Tamil).
- 🎨 **Academic Prestige Color Palette:** Handcrafted with authority and comfort:
  - `#010736` — Deep Midnight Navy (Dark mode canvas & primary dark text)
  - `#0D1C42` — Rich Dark Surface (Cards, elevated containers, dropdowns)
  - `#22396F` — Royal Slate Accent (Primary CTAs, badges, focused borders)
  - `#FCF1D0` — Warm Parchment Cream (Badges, solution highlights, selected card accents)
- 🌓 **Dark & Light Mode:** Zero-FOUC theme toggle with preference persistence in `localStorage`.
- 🔒 **100% Client-Side Privacy:** Zero server tracking, zero advertisements, and no registration required. All scoring happens locally in the browser.
- 🚀 **SEO & SERP Dominance:**
  - Semantic HTML optimized for high-intent search queries (`sinhala IQ papers`, `srilanka iq papers`, `goverment exam iq papers sinhala`).
  - Google Rich Results JSON-LD Schemas (`WebSite`, `EducationalOrganization`, `Quiz`, and `FAQPage`).
  - Autogenerated `sitemap.xml` with multilingual `hreflang` alternates and `robots.txt`.

## 🎯 Target Sri Lankan Examinations

The model papers and curriculum modules are aligned with the official syllabi of:

1. **SLAS (Sri Lanka Administrative Service)** — Open & Limited Competitive Exams
2. **Banking Competitive Examinations** — Bank of Ceylon (BOC), People's Bank, National Savings Bank (NSB), Central Bank of Sri Lanka (CBSL)
3. **Development Officers' Service (සංවර්ධන නිලධාරී විභාගය)**

5. **Public Management Assistant Service (PMAS - කළමනාකරණ සේවා නිලධාරී)**
6. **Sri Lanka Police & Customs Inspections**

## 📝 How to Add a New Exam Paper

All papers are stored in `src/content/papers/` as Markdown (`.md`) files with YAML frontmatter validated against `src/content/config.ts`:

1. Create a new file in `src/content/papers/`, e.g., `iq-model-paper-03-si.md`.
2. Populate the YAML frontmatter structure:

```yaml
---
title: "ශ්‍රී ලංකා පරිපාලන සේවය සහ බැංකු විභාග බුද්ධි පරීක්ෂණ ආදර්ශ පත්‍රය 03"
language: "si" # "si" | "en" | "ta"
durationMinutes: 60
description: "රාජ්‍ය සේවා තරඟ විභාග සඳහා කෙටි ක්‍රම සහිත බුද්ධි පරීක්ෂණ ප්‍රශ්නාවලිය."
category: "බුද්ධි පරීක්ෂණය සහ ගණිතමය තර්කනය"
questions:
  - id: 1
    question: "පහත සංඛ්‍යා රටාවේ මීළඟට එන සංඛ්‍යාව කුමක්ද? 4, 9, 25, 49, 121, 169, ?"
    options:
      - "196"
      - "225"
      - "289"
      - "361"
    correctIndex: 2
    shortMethod: "ප්‍රථමක සංඛ්‍යාවල වර්ග: 2², 3², 5², 7², 11², 13². 13 න් පසු මීළඟ ප්‍රථමකය 17 වේ. එබැවින් 17² = 289."

  - id: 2
    question: "මිනිසුන් 8 දෙනෙකුට දින 12 කින් කළ හැකි කාර්යයක් මිනිසුන් 6 දෙනෙකුට කිරීමට ගතවන දින ගණන කීයද?"
    options:
      - "14"
      - "15"
      - "16"
      - "18"
    correctIndex: 2
    shortMethod: "මුළු මිනිස් දින = 8 × 12 = 96. මිනිසුන් 6 දෙනෙකුට ගතවන දින ගණන = 96 ÷ 6 = 16 දින."
---
```

3. Astro automatically generates the static route `/papers/iq-model-paper-03-si` at build time!

## 🛠️ Local Development & Scripts

### Prerequisites
- **Node.js**: v18.0.0 or higher (v20+ recommended)
- **npm**: v9.0.0 or higher

### 1. Clone the repository
```bash
git clone https://github.com/slgoviq/slgoviq.github.io.git
cd slgoviq.github.io
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open [http://localhost:4321](http://localhost:4321) in your browser.

### 4. Run type & schema validation
```bash
npm run check
```

### 5. Build for production (SSG)
```bash
npm run build
```
Generates production-ready, pre-rendered static HTML and optimized client assets in the `dist/` directory.

### 6. Preview production build locally
```bash
npm run preview
```

## 🚀 Deployment to GitHub Pages

This project is configured for seamless deployment to **GitHub Pages**:

1. In `astro.config.mjs`, `site` is configured as `https://slgoviq.github.io`.
2. Push your changes to the `main` branch.
3. In your GitHub repository settings, go to **Settings** > **Pages** and set the source to **GitHub Actions** (or publish the `dist/` directory).
